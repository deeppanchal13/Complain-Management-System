# 🏫 College Complaint Management System

A console-based **College Complaint Management System** built using C++ and Object-Oriented Programming (OOP). It allows students to register complaints related to the mess, hostel, and college, while admins and wardens can view registered complaints.

## ✨ Features

- Student portal to raise and view complaints.
- Separate complaint categories: Mess, Hostel, and College.
- Admin portal to view all complaints.
- Warden portal to manage mess and hostel complaints.
- Password-based authentication.
- File handling for persistent complaint storage.
- OOP concepts using classes, inheritance, and encapsulation.

## 🛠️ Technologies Used

- C++
- OOP
- File Handling (`fstream`)

## 🚀 How to Run

1. Clone this repository.
2. Compile the C++ source file using a C++ compiler.
3. Run the generated executable.
4. Select a portal from the main menu.

## 📁 Storage

Complaints are stored in separate text files inside the `Complaints` directory.
